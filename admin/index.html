One-time setup: unlock the automations

Do these once. They let the console set up email and forms for a shul in one click. Every secret goes in Supabase → daas-control → Edge Functions → Secrets (never in chat).
1. AWS key for email setup (about 5 minutes)
  1. Sign in to the DAAS AWS account → search IAM → Users → Create user. Name it daas-onboarding. Leave console access off. Click Next.
  2. Choose Attach policies directly → Create policy (opens a new tab) → switch to JSON and paste the policy below → Next → name it daas-onboarding → Create policy.
  3. Back on the user tab, click the refresh icon, tick daas-onboarding → Next → Create user.
  4. Open the user → Security credentials → Create access key → choose Application running outside AWS → Create.
  5. In Supabase daas-control secrets add AWS_ADMIN_ACCESS_KEY_ID and AWS_ADMIN_SECRET_ACCESS_KEY with those two values.
IAM policy JSON (click to show)

2. Cloudflare token for the forms address (about 3 minutes)
  1. Cloudflare dashboard → profile icon (top right) → My Profile → API Tokens → Create Token → Create Custom Token.
  2. Name it daas-onboarding. Permissions: Account · Cloudflare Pages · Edit. Account resources: your account. → Continue → Create Token.
  3. Copy the token into the Supabase secret CLOUDFLARE_API_TOKEN.
  4. Your Account ID is on the right side of any domain's Overview page in Cloudflare (or in the URL after dash.cloudflare.com/). Save it as CLOUDFLARE_ACCOUNT_ID.
3. Check it
  • Come back here and click Run checks. AWS, SNS, SES and Cloudflare should all say ok.
